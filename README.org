#+TITLE: Autumntree
#+AUTHOR: kiskami

My entry for the Autumn Lisp Game Jam 2026
(https://itch.io/jam/autumn-lisp-game-jam-2026)

This is a simple game, where you poke the leaves on a tree.

Please see the itch.io page for status, devlog and screenshots:
https://kiskami.itch.io/autumntree

* How to install and run the binaries

The game package contains the source, licenses and the dynamic
loadables necessary to run it on Linux and Windows.
After unpacking you have two options:

** If you don't have Raylib and claw-raylib installed

I packed my versions of them (in the ~redist~ directory on Linux);
hope that they work on your OS too. I use ~Slackware~ current and built
and tested the Windows version in ~Wine~... :)

On Linux, ~chmod +x run.sh autumntree~, run the ~run.sh~
shell script and enjoy! ;)

On Windows you run the ~autumntree.exe~.

** If you have Raylib and claw-raylib adapter installed

Nice. You are already developing Raylib games with claw-raylib.
You have the knowledge and necessary dynamic loadables and
are able to run ~raylib~ *5.5* based apps.

*** Beware
There is a bug (?) in claw-raylib, where if running on Windows (not
on Linux) the lib is looking for a dll named ~libraylib.dll~ but
there is only a ~raylib.dll~ - so you have to modify the foreign
library name in the ~library.lisp~ file of claw-raylib.

* How to load and run from source

This project is developed with:
- ~SBCL~ - https://www.sbcl.org/
- ~Raylib 5.5~ - https://www.raylib.com/index.html
- ~claw-raylib~ - https://github.com/bohonghuang/claw-raylib
- and of course ~Emacs + Slime~

** Installing the dependencies

1. Install *Raylib 5.5* on your OS
2. Get claw-raylib for 5.5 and build it (The *prebuilt 5.5* branch
   helps)
   - Get and install deps for quicklisp as local projects:
     *cffi-object, cffi-ops*
   - Install claw-raylib as local quicklisp project
   - You'll have to install the compiled adapter libs to the
     appropriate location according to your OS - most likely
     the same place where your Raylib libs reside and can be
     loaded by the game/sbcl.
3. Get this source and configure as quicklisp local project

The following raylib and claw-raylib dynamic loadables should be
loadable by sbcl or app:

#+begin_src CLI
  /usr/local/lib64$ ls -1 *ray*
  libraylib-adapter.so
  librlgl-adapter.so
  libraylib.so
#+end_src


** Running

Load it with asdf or quicklisp and run the ~main~ function:
#+begin_src
  CL-USER> (asdf:load-system :autumntree)
  ...
  T
  CL-USER> (autumntree:main)
#+end_src
